# stopwatch

终端秒表：计圈 + 倒计时，纯标准库。

## 玩法

```bash
python -m stopwatch            # 秒表: 回车=计圈, q=退出
python -m stopwatch --countdown 10   # 10 秒倒计时, 到时哔哔
```

交互模式下实时显示当前用时；每次回车记一圈，并显示本圈 / 最快圈 / 总计。
倒计时支持小数秒（`--countdown 1.5`）。

## 设计取舍

- 计时用 `time.monotonic()`，不受系统时间调整影响。
- `Stopwatch` 类接受注入时钟，圈速逻辑可单元测试。
- 刷新线程 50ms 更新一次显示，练习够用；不是录音室级精度。

## 已知局限

- 行输入模式：每步需回车，不支持即时按键（需终端 raw 模式）。
- 交互模式需要 tty；管道输入会直接报错退出。
- 铃声只是 `\a` 请求，实际效果取决于终端。
- 秒表无暂停/继续，只有计圈和停止。
